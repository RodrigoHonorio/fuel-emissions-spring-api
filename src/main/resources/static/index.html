S.P.I.R.E. Engine

Ative para projetar os cálculos de emissão VOC sobre a rede de postos.

Metodologia S.P.I.R.E.

O motor implementa a metodologia CETESB 2015 para o cálculo de emissões evaporativas em postos, adaptada para as condições meteorológicas de Londres.

  • Perdas por Enchimento: Fator de emissão de 0,89 g/L (Gasolina).
  • Clima: Dados horários dinâmicos da malha meteorológica.
  • Vazão Anual: Estimada com base na capacidade da bomba.
